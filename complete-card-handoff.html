Complete Card

Working name — final class/tag name TBD. Source: Shoebox v11 income upload mock. Colton Bragg (UX) · 2026-08-05, updated 2026-08-14 · Handoff for @taxhawk-swoop/common.

Purpose

One card per uploaded document on the upload page. Three states: ready to import (confirm the detected form type or remove the file), uncategorized (warning treatment with an explanation block), and upload failed (error treatment). Desktop layout plus a stacked mobile layout below 576px.

Instances

The badge is the live form-type selector. Switching a card to Uncategorized converts it to the warning variant in place. A failed upload shows the error variant.

Default — one card per uploaded file, including a long-filename case.

Anatomy

PartSpec
File-type iconOfficial set (32×40, Figma node 4605-20616 — download as provided; static multi-color SVGs, not mask icons), one per card, leading. Error variant: generic document icon instead (files/file-01.svg, 20×20 stroke, $danger-600).
FilenameText md/Medium, $text-default. Max two lines, then ellipsis — all breakpoints.
Status lineText sm/Regular. “Ready for import” ($text-help); error: “Upload failed, please try again” ($text-subtle).
Form-type badgeThe package badge (.badge.badge-primary.clickable / .badge-warning.clickable) over an invisible native <select>. The only classification control. Not rendered in the error variant. See the badge differences section below.
Remove button40×40 icon button, 24px x-close, $text-default, aria-label="Remove <filename>". Hover: variant surface tint + mix-blend-mode: multiply — brand at shade 50, warning/danger at 100 (50 reads too faint on the warm 25 surfaces).
Warning blockUncategorized only: divider ($border-warning), alert-triangle ($svg-warning), “Uncategorized Document” title, body with My Tax Files link. Added/removed in place as the badge changes; aria-live="polite".

Behavior

  1. The badge opens a native <select> with the full SWOOP form-type list. The label updates immediately.
  2. Uncategorized ↔ default converts in place, adding or removing the warning block.
  3. A failed upload shows the error variant. Recovery is remove and re-upload.
  4. Remove deletes the card with no confirmation (recoverable by re-uploading).
  5. Only the badge and remove button are interactive. The card itself is not clickable.

Accessibility

  • The badge must remain a real <select>. Focus ring via the JS-toggled .focused class.
  • Warning block and error status changes announce via aria-live="polite" aria-atomic="false".
  • Remove button: aria-label="Remove <filename>". All icons aria-hidden="true".
  • Text/surface pairs meet 4.5:1 contrast.

Build Notes

  • Ships in @taxhawk-swoop/common: _complete_card.scss plus a docs page. Single base class with variant modifiers.
  • Missing tokens are FIXME-marked in the SCSS. No raw hex, no scoped overrides of other components.
  • New mask-icon URLs need pre-loading in _theme.scss (:root::after).
  • JS (badge label sync, variant toggle, .focused/.open) lives in the package’s index.js.
  • Class names are working names. Final naming TBD at build.

Do / Don’t

DoOne card per uploaded file, stacked oldest-first, 8px gap.
Don’tReuse for in-progress uploads (failed uploads are this component; in-progress is not), add extra action buttons, or use outside an upload list.

Badge Differences from the Package Badge

This badge differs from the package badge (_badge_new.scss) in three ways. Pick a side on each before building:

  • Type size: mock is Text sm/Medium (14/20); package badge is textXSMed (12/18).
  • Padding: mock is 2px 4px 2px 8px (tighter right edge around the chevron); package is 2px 8px.
  • Hover: mock darkens the text ($brand-700 / $warning-800, no tokens) and underlines; package badge only changes surface/border on hover and underlines on focus.

Reference SCSS — Proposed _complete_card.scss

The spec of record, written to package conventions: tokens with FIXME comments where none exists, font-props/svg-mask-full/shadow mixins, no :has() (JS-toggled classes instead). The badge reuses the package badge — this file only adds the <select> overlay.

// Complete Card (Components)
//
// One uploaded document that finished uploading and is ready to import.
// Base (brand) card + .uncategorized (warning) variant with attached message block.
// Form-type badge reuses .badge styles from _badge_new.scss with a native <select> overlay.

.complete-card {
	@include border-radius($radius-sm);

	& {
		background: $surface-brand-light;
		border: $border-width solid $border-brand;
		overflow: hidden;
	}

	.complete-card-body {
		display: flex;
		align-items: center;
		justify-content: space-between;
		padding: $scale-400;
	}

	.complete-card-left {
		display: flex;
		align-items: center;
		gap: $scale-400;
		min-width: 0;
	}

	.file-icon {
		width: 32px;
		height: 40px;
		flex-shrink: 0;
	}

	.complete-card-info {
		display: flex;
		flex-direction: column;
		min-width: 0;
	}

	.complete-card-name {
		@include font-props(textMDMed);

		& {
			display: -webkit-box;
			-webkit-line-clamp: 2;
			-webkit-box-orient: vertical;
			overflow: hidden;
			overflow-wrap: anywhere;
		}
	}

	.complete-card-status {
		@include font-props(textSM);

		& {
			color: $text-help;
		}
	}

	// Form-type selector: package badge + invisible native <select> overlay.
	// The <select> must stay a real element (a11y). Focus ring comes from a
	// JS-toggled .focused class (index.js focus tracking) — no :has().
	.badge {
		& {
			position: relative;
			flex-shrink: 0;
			margin-inline-start: $scale-200;
		}

		.badge-select {
			position: absolute;
			top: 0;
			left: 0;
			width: 100%;
			height: 100%;
			opacity: 0;
			cursor: pointer;
		}

		&.focused {
			@include shadow($blue-box-shadow);
		}
	}

	.complete-card-close {
		@include border-radius(50%);

		& {
			width: 40px;
			height: 40px;
			flex-shrink: 0;
			display: flex;
			align-items: center;
			justify-content: center;
			background: none;
			border: none;
			cursor: pointer;
		}

		[data-th-icon] {
			@include svg-mask-full('#{$icon-base-path}/general/x-close.svg', center center, 24px 24px, no-repeat);

			& {
				width: 24px;
				height: 24px;
			}
		}

		// Icon-button hover convention (per dev): shade-50 surface token
		// blended into the card surface with mix-blend-mode: multiply
		&:hover {
			background: $surface-brand;
			mix-blend-mode: multiply;
		}

		&:focus-visible {
			@include shadow($blue-box-shadow);

			& {
				outline: none;
			}
		}
	}

	// Divider + message exist only in the uncategorized variant
	.complete-card-divider {
		height: $border-width;
		margin: 0 $scale-400;
		background: $border-warning;
	}

	.complete-card-message {
		display: flex;
		gap: $scale-400;
		padding: $scale-400;

		[data-th-icon] {
			@include svg-mask-full('#{$icon-base-path}/alerts-feedback/alert-triangle.svg', center center, 24px 24px, no-repeat, $svg-warning, $icon-warning);

			& {
				width: 24px;
				height: 24px;
				flex-shrink: 0;
			}
		}

		.message-content {
			display: flex;
			flex-direction: column;
			gap: $scale-100;
		}

		.message-title {
			@include font-props(textMDSemi);

			& {
				color: $text-subtle;
			}
		}

		.message-text {
			@include font-props(textMD);

			& {
				color: $text-subtle;
			}

			a {
				color: $text-link;

				&:hover {
					color: $text-link-hover;
					text-decoration: underline;
				}
			}
		}
	}

	&.uncategorized {
		& {
			background: $surface-warning-light; // new token, approved 2026-08-14 = $warning-25
			border-color: $border-warning;
		}

		.badge.focused {
			@include shadow($yellow-box-shadow);
		}

		.complete-card-close {
			&:hover {
				background: $surface-warning-hover; // one shade up ($warning-100) — warning-50 reads too faint over the warning-25 card; multiply inherited
			}

			&:focus-visible {
				@include shadow($yellow-box-shadow);
			}
		}
	}

	&.upload-error {
		& {
			background: $surface-danger-light; // new token, approved 2026-08-14 = $danger-25
			border-color: $border-danger;
		}

		// No badge in the error state (no detected form type); the file-type
		// icon is replaced by the generic document icon in the error color.
		// Status copy is fixed: "Upload failed, please try again"
		.generic-file-icon {
			@include svg-mask-full('#{$icon-base-path}/files/file-01.svg', center center, 20px 20px, no-repeat, $danger-600, $filter-danger-600); // FIXME: missing token - notify UX ($svg-danger is danger-500)

			& {
				width: 20px;
				height: 20px;
				flex-shrink: 0;
			}
		}

		.complete-card-status {
			color: $text-subtle;
		}

		.complete-card-close {
			&:hover {
				background: $surface-danger-hover; // one shade up ($danger-100) — danger-50 reads too faint over the danger-25 card; multiply inherited
			}

			&:focus-visible {
				@include shadow($red-box-shadow);
			}
		}
	}

	// Mobile (<576px): top-align, badge drops to a second line under the text column
	@include media-breakpoint-down(sm) {
		.complete-card-body {
			align-items: flex-start;
		}

		.complete-card-left {
			display: grid;
			grid-template-columns: 32px 1fr;
			column-gap: $scale-400;
			row-gap: $scale-200;
			align-items: start;
		}

		.badge {
			grid-column: 2;
			justify-self: start;
			margin-inline-start: 0;
		}
	}
}
